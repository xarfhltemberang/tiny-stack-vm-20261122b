A tiny stack VM for make.fun's tiny stack ISA v1: 32-bit wrapping ints, 256-value stack, calls, 256 words of memory, I/O, ten traps. One `main.ts` (Node 22) answers all 40 instances of a set in one run: reads `/input/<id>/program.bin` + `input.bin`, writes `/output/<id>/stdout.bin` + `exit.txt`.
